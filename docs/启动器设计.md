# 新启动器设计（自研，替换 CoZ 外观）

> 目标：补丁在**外观上是一个新的汉化补丁**，不使用 CoZ 的图形化启动器、图标、品牌与链接。
> 运行时骨骼仍是 LanguageBarrier（不可替换，它是补丁的加载器），但**玩家可见的界面全部自研**。

---

## 1. 现状（CoZ 外观残留）

| 文件 | 问题 |
|---|---|
| `LauncherC0.exe` | **CoZ 图形化启动器**：英文界面、CoZ 图标与品牌、"Version: QA1"、指向 CoZ 的 Discord/下载页 |
| `RNDPatch-README.txt` | 已换成中文版（本仓 `docs/补丁说明.md`）✅ |
| `Qt5Core/Gui/Svg/Widgets.dll`、`iconengines/`、`imageformats/`、`platforms/`、`styles/`、`libcurl.dll` | Qt5 运行库 + 更新用 libcurl。**若新启动器也用 Qt5 则保留**；若不用则可换 |
| `NOTES DaSH/d3d9`…`dxgi` | DXVK 相关（与启动器无关，保留） |

## 2. 启动链路（当前实现）

```
Steam 启动
  └ boot.bat:  start RNDZhLauncher.exe JP    ← ★ 安装器写的就是这一行
      └ 自研启动器（玩家设置 cosplay/字幕/鼠标/DXVK）
          └ 玩家点「开始游戏」
              └ 启动 Game.exe roboticsnotesd <JP|EN>
                  └ Game.exe 静态导入 DINPUT8 → 代理 DLL 起效 → 中文文本/图集
```

**为什么不是 hijackLauncher**：`patchdef.json` 里确实配着
`"hijackLauncher": "RNDZhLauncher.exe"`，那条分支（`LanguageBarrier.cpp:251`）的意图是
"MAGES 启动器加载了我们的 dinput8.dll → LB 检测到 `canaryMagesLauncher` → 杀掉它并换成
自研启动器"。但**这个游戏上它永远不会触发**：MAGES 的 `launcher.exe` 根本不导入 DINPUT8
（实测导入表只有 KERNEL32/USER32/GDI32/MSIMG32/WINSPOOL/ADVAPI32/SHELL32/COMCTL32/
SHLWAPI/UxTheme/ole32/OLEAUT32/oledlg/gdiplus/OLEACC/IMM32/WINMM，且无延迟导入），
代理 DLL 加载不进去 → `log.txt` 不生成、启动器进程里扫不到任何 dinput8 模块。
（`canaryMagesLauncher` 特征码确实能在 `launcher.exe` 里命中，但那要 DLL 先进得去才有意义。）

→ 所以**改 `hijackLauncher` 对 Windows 路径没有效果**，实际做法是**直接改 `boot.bat`**
指向自研启动器。CoZ 也是这么做的（`start LauncherC0.exe`），
`proton_boot_fix.sh` 里的 `ln -s RNDZhLauncher.exe boot.bat` 同理。

> 保留 `hijackLauncher` 配置项无害（对 Game.exe 那条路径它也不会触发，
> 因为 Game.exe 命中的是 `canary` 而不是 `canaryMagesLauncher`）；删不删都不影响。

## 3. 新启动器要做的事

### 3.1 必需
1. **显示自己的品牌**（名字/图标/配色，无任何 CoZ 字样）
2. **读写设置**（可复用 CoZ 的 settings 机制，也可自研）：
   - 配置路径 = `%LOCALAPPDATA%\<patchdef.appdatadir>\config.json`
   - 键与 `patchdef.json` 的 `settings` 对应（`mouseControls`/`scrollDownToAdvanceText`/
     `disableScrollDownToCloseBacklog`/`swimsuitPatch`/`karaokeSubs`/`hideAutoSkip`）
   - 写出的 JSON 格式：`{ __schema_version, <setting>: <value>, ... }`
3. **启动 `Game.exe`**（工作目录=游戏根目录）

### 3.2 建议
4. 分辨率/全屏选择（原启动器有，写入 `Game.exe` 的配置或命令行）
5. **不要**自动指向 CoZ 的更新地址（`versioninfo.json` 已改为本仓库地址；
   若暂不发布 `update.json`，启动器应静默跳过或提示"检查失败"，不得跳 CoZ 页面）
6. 版本号显示为**自己的补丁版本**

## 4. 替换步骤（实际做法）

1. 新启动器编译为 `RNDZhLauncher.exe`，放进游戏根目录（payload 里带上）
2. **安装器写 `boot.bat` 时指向它**（`RNDZhSetup.cpp` 第 7 步）—— 这是真正生效的那一步
3. 删除 `LauncherC0.exe`
4. 若新启动器不用 Qt5：可一并删除 `Qt5*.dll`、`iconengines/`、`imageformats/`、
   `platforms/`、`styles/`、`libcurl.dll`
5. 若新启动器是自绘（非 Qt），体积可大幅缩小

> `patchdef.json` 的 `hijackLauncher` 也指向 `RNDZhLauncher.exe`，但它**不是**生效路径
> （见 §2 的原因），保留只为配置自洽。

## 5. 若暂时不做新启动器

**最小可用方案**：保留一个极简启动器（哪怕是个批处理/自写小 exe），只做"开始游戏"，
避免玩家看到 CoZ 的品牌与英文界面。此时：
- 把 `boot.bat` 指向它（**不是** `hijackLauncher`，那个不生效）；
- 游戏内设置仍走 `config.json`（玩家可手改，或提供一个小设置界面）。

> 注意：**不能让 `boot.bat` 继续指向原版 `launcher.exe`** —— 那是 MAGES 自家的
> 「Start Game / Screen Setting / Quit」窗口，玩家会先看到它而不是补丁启动器
> （补丁在游戏里照样生效，但玩家得先点一次 Start Game）。
> 而我们的启动器要设置 DXVK/字幕/cosplay 等开关，所以第一次仍建议打开它一次。

## 8. 图标（2026-09-11 完成）

**用游戏自己的图标**（用户指定）：从 `Game.exe` 提取其内嵌图标组（RT_GROUP_ICON），
包含 **32 / 64 / 128 / 256** 四档，打成 `launcher/icon/game.ico`（359 KB），
经 `launcher.rc`（`101 ICON "icon/game.ico"`）在编译时嵌入 `RNDZhLauncher.exe`。

- **窗口/任务栏图标**：`LoadIconW(hInst, MAKEINTRESOURCEW(101))`
- **界面左侧品牌区**：运行时从自身 exe 的 `RT_ICON` 资源取最大一张（256×256），
  用 `CreateIconFromResourceEx` → `DrawIconEx` 转成 GDI+ Bitmap，圆角裁剪后绘制。
- 提取脚本：`launcher/` 内已附 `icon/game.ico`；重新生成见下方说明。

> 重新提取图标（若需）：解析 `Game.exe` 的 `.rsrc` 段，取 RT_GROUP_ICON 的成员列表，
> 逐个取对应 RT_ICON 数据，按 ICO 格式拼装（32bpp BMP 载荷）。

## 9. 已知问题与注意

| 项 | 说明 |
|---|---|
| **`dinput8.dll` 的生效位置 = `NOTES DaSH\`** | 游戏从该子目录加载补丁 DLL。根目录那份是备用，**不是必需**。（此前本文档写反，2026-09-11 实测更正：把 `NOTES DaSH\dinput8.dll` 改名后补丁完全失效，放回即恢复。）补丁包与安装器**两处都放**以防万一。 |
| **必须装在 Steam 认的目录** | `Game.exe` 静态导入 `steam_api.dll`；把游戏目录改名/移出 Steam 库会导致进程在启动极早期（仅加载 7 个模块）卡住，补丁 DLL 根本没机会加载。**这是"补丁没效果"的最常见原因。** |
| **`DINPUT8.dll` 是补丁的加载入口** | `Game.exe` 与启动器都静态导入它。启动器必须导入（已办），否则双击启动器不会加载补丁。 |
| 日/英双版本 | `MES00`（日）/`MES01`（英）都要重定向到 `enscript`，见 `docs/版本兼容.md` |
| 启动器字体 | 用系统中文字体（GDI+ 无法加载 CFF/OTF，即游戏自带的 NotoSansCJKsc.otf） |
| 图标 | 已用游戏原图标 |
